📄 GitHub Pages用：Lodestone HTMLを読み込む
完全自動同期がCORSで止まる場合はこちらを使えます。Lodestoneの「プロフィール」ページと、必要なら「クラス・ジョブ」ページをHTMLで保存し、ここへ読み込ませてください。公開情報を手入力し直す必要はありません。
取得について
公開プロフィールだけを対象にします。GitHub Pagesは静的サイトのため、ブラウザからLodestoneへの直接取得はCORSで失敗する場合があります。その場合はHTML読込を使えます。将来バックエンドを用意すれば、この画面のIDから完全自動同期へ切り替えられます。取得に失敗しても前回保存したプロフィールは削除しません。

保存について

・通常保存：localStorage と IndexedDB の両方へ同じ最新データを保存します。

・JSONバックアップ：ブラウザの外へ保存するため、ブラウザ履歴・サイトデータ削除への備えになります。

・復元：バックアップ内容を現在の正式データとして両方の保存領域へ同期します。

・旧版データは自動削除しません。
